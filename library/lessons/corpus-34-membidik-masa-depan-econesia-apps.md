## The useful argumentative move

**A changed state affects the next opportunity**

Follow how learning changes a profile and that changed profile changes a subsequent opportunity. This is a feedback loop rather than simply colocated modules.

The transferable sequence is:

**Experience → updated state → next opportunity → continued progression.**
