## Scope of the audit

This build recovered and verified source bytes, page counts, archive safety, identity, completeness of the available collection and image correspondence. It preserves the earlier reading receipts; it does not claim a new complete reread of every source page. A future claim taken from a reference still requires reading its actual relevant source and checking its scope.

The library is intentionally extensive. Read the current task’s uploads and guidebook completely, and use the catalog/reading routes to select reference material. The presence of a file does not require importing its subject, framework, evidence, design or assumptions into every essay.
